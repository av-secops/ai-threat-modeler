# Aegis Threat 2.3.1

Updated 7 September 2026. This refresh keeps the existing `v2.3.1` version and
tag; downloading the tag again returns the updated source.

## Included Changes

- Guided architecture and IaC review before analysis, editable drafts, saved
  revisions, source evidence, and automatic diagram previews after edits.
- Prompt/document claim correlation, scoped control states, expanded security
  knowledge, IaC checks, retrieval tooling, and regression tests.
- Separate report, architecture, risk-register and assurance views, with finding
  details, filters, review decisions, and light/dark styling.
- Reworked Windows startup scripts with a local virtual environment, dependency
  checks, custom ports, readiness checks, background logs, and owned-process
  shutdown. Existing servers are left alone. Startup does not download models.
- A pip-compatible root requirements file, synchronized backend/training
  dependencies, Node 22.13+ requirements, updated Docker/CI runtimes, and Windows
  launcher tests in CI.

## Local Verification

## Known Limitations

The [Nexora telecom review](../scenarios/nexora-telecom-26.09/chrome-review-2026-09-07.md)
identified missed declared weaknesses, unsupported confirmed findings, scope and
data-classification errors, a false conflict blocking final PDF export, and
diagram boundary/flow omissions. Those defects remain open in this refresh.

Use the application to assist a technical review, not to approve security
sign-off automatically. Neither a "Confirmed" label nor "100% STRIDE assessed"
means a deployed system was tested or every threat was detected.

Local credentials, browser workspace exports, raw reviewer feedback, generated
evaluation output, virtual environments, and large model checkpoints are not
included. Synthetic training fixtures and their historical reports are included;
their scores are not an independent estimate of production accuracy.

See the [README](../../README.md) for installation and model-prefetch instructions.
